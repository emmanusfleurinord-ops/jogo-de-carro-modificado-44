# 🏎️ Turbo Rush 2D

Jogo de corrida 2D estilo arcade onde você precisa desviar dos carros inimigos, completar objetivos de nível e sobreviver o máximo possível.

Versão melhorada com **faróis realistas**, **setas de direção** e **som de motor mais autêntico**.

---

## ✨ Principais Características

- **Carro do jogador detalhado**
  - Faróis dianteiros brilhantes com efeito de luz
  - Setas de direção (esquerda e direita) que piscam ao mudar de faixa
  - Lanternas traseiras
  - Glow neon e detalhes visuais aprimorados

- **Som de motor realista**
  - Motor com dois osciladores + filtro lowpass
  - Frequência e volume reagem à velocidade do carro
  - Som de colisão e música de fundo

- **Sistema de níveis**
  - 5 níveis com objetivos diferentes (tempo ou pontuação)
  - Modo Infinity (sobreviva o máximo que conseguir)

- **Sistema de vidas** (5 corações)
- **Pausa** (P ou ESC)
- **Tela cheia**
- **Ranking de melhores pontuações** (salvo no navegador)
- **Ajuda** (tecla F1)

---

## 🎮 Controles

| Tecla       | Ação                      |
|-------------|---------------------------|
| ← →         | Mudar de faixa (ativa as setas) |
| ↑           | Acelerar                  |
| ↓           | Frear                     |
| P ou ESC    | Pausar / Continuar        |
| F1          | Abrir / Fechar ajuda      |

---

## 🏁 Níveis

| Nível | Objetivo                    |
|-------|-----------------------------|
| 1     | Sobreviva 40 segundos       |
| 2     | Faça 1.500 pontos           |
| 3     | Sobreviva 55 segundos       |
| 4     | Faça 2.500 pontos           |
| 5     | Sobreviva 80 segundos (Difícil) |
| ∞     | Modo Infinity (sobreviva o máximo possível) |

---

## 🚀 Como Jogar

1. Baixe o arquivo `turbo-rush-2d.html`
2. Abra o arquivo no navegador (Chrome, Firefox, Edge, etc.)
3. Clique em **Iniciar Corrida**
4. Escolha o nível e divirta-se!

> Não precisa de instalação nem de servidor. É um único arquivo HTML.

---

## 🛠️ Tecnologias Utilizadas

- HTML5 Canvas
- JavaScript (puro)
- CSS3 (estilos neon)
- Web Audio API (som de motor e efeitos)
- LocalStorage (salvar ranking)

---

## 📸 Recursos Visuais

- Interface com tema neon (vermelho, amarelo e ciano)
- Fonte Orbitron + Rajdhani
- Partículas de faísca na colisão
- Fumaça de escape ao acelerar
- Efeito de invencibilidade (pisca) após bater
