# 🏎️ Turbo Rush 2D

Jogo de corrida 2D estilo arcade onde você precisa desviar dos carros inimigos, completar objetivos de nível e sobreviver o máximo possível.

Versão completa com **faróis realistas**, **setas de direção**, **som de motor autêntico**, **100 níveis difíceis**, **Multiplayer Local** e **suporte a controle de videogame**.

---

## ✨ Principais Características

### Carro do jogador
- Faróis dianteiros brilhantes com efeito de luz
- Setas de direção (esquerda e direita) que piscam ao mudar de faixa
- Lanternas traseiras
- Glow neon e detalhes visuais aprimorados

### Som de motor realista
- RPM virtual que sobe e desce como um carro de verdade
- Reage quando você acelera e quando freia
- Volume e tom mudam conforme a velocidade

### Estrada detalhada
- Guardrails (barreiras metálicas) nas laterais
- Grama com textura
- Linha central amarela dupla
- Faixas tracejadas brancas com brilho
- Postes de luz que passam rápido
- Reflexo no asfalto em alta velocidade

### Sistema de níveis
- **100 níveis** com desafios progressivos e bem difíceis
- Objetivos de sobrevivência (tempo) e de pontuação
- Níveis especiais extremamente difíceis
- Nível 100 = Desafio Final (sobreviva 360 segundos)

### Multiplayer Local
- 2 jogadores no mesmo computador
- Digite o nome de cada jogador antes de começar
- Tela cheia automática ao iniciar
- Cada jogador tem suas próprias vidas
- Funciona com teclado **e** controle de videogame

### Outros
- Sistema de vidas (5 corações)
- Pausa (P ou ESC)
- Tela cheia
- Ranking de melhores pontuações (salvo no navegador)
- Ajuda (tecla F1)

---

## 🎮 Controles

### Single Player
| Tecla       | Ação                          |
|-------------|-------------------------------|
| ← →         | Mudar de faixa (ativa as setas) |
| ↑           | Acelerar                      |
| ↓           | Frear                         |
| P ou ESC    | Pausar / Continuar            |
| F1          | Abrir / Fechar ajuda          |

### Multiplayer Local
| Jogador     | Teclado              | Controle de Videogame          |
|-------------|----------------------|--------------------------------|
| **Jogador 1** | Setas ← → ↑ ↓      | Controle 1 (Stick / D-pad + A/B) |
| **Jogador 2** | **WASD**            | Controle 2 (Stick / D-pad + A/B) |

**Controle de videogame:**
- Stick esquerdo ou D-pad → mudar de faixa
- Botão A / Trigger direito → acelerar
- Botão B / Trigger esquerdo → frear

## 🏁 Níveis

| Nível      | Tipo de Desafio                              |
|------------|----------------------------------------------|
| 1–20       | Introdução + primeiros desafios              |
| 21–50      | Dificuldade média-alta                       |
| 51–80      | Desafios muito difíceis                      |
| 81–99      | Extremamente difíceis                        |
| **100**    | **Desafio Final** – Sobreviva 360 segundos   |

## 🚀 Como Jogar

1. Baixe o arquivo `turbo-rush-2d.html`
2. Abra o arquivo no navegador (Chrome, Firefox, Edge, etc.)
3. Clique em **Iniciar Corrida** (Single Player) ou **Multiplayer Local**
4. No Multiplayer: digite os nomes e clique em Iniciar
5. Divirta-se!

> Não precisa de instalação nem de servidor. É um único arquivo HTML.
